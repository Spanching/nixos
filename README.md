
# Nixos Configuration

## River

### Keymappings:


| **Keybinding / Command**                     | **Action**                                                                                                                                                           |
|----------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `Super+Shift Return`                         | Spawn **Alacritty** terminal.                                                                                                                                         |
| `Super D`                                    | Spawn **wofi** launcher (with `--show run` to show the run dialog).                                                                                                  |
| `Super+Alt Return`                           | Spawn **Foot** terminal.                                                                                                                                              |
| `Super Q`                                    | Close the focused view.                                                                                                                                               |
| `Super+Shift E`                              | Exit the session.                                                                                                                                                     |
| `Super J`                                    | Focus the next view in the layout stack.                                                                                                                             |
| `Super K`                                    | Focus the previous view in the layout stack.                                                                                                                         |
| `Super+Shift J`                              | Swap the focused view with the next one in the layout stack.                                                                                                        |
| `Super+Shift K`                              | Swap the focused view with the previous one in the layout stack.                                                                                                    |
| `Super Period`                               | Focus the next output (monitor).                                                                                                                                      |
| `Super Comma`                                | Focus the previous output (monitor).                                                                                                                                  |
| `Super+Shift Period`                         | Send the focused view to the next output (monitor).                                                                                                                   |
| `Super+Shift Comma`                          | Send the focused view to the previous output (monitor).                                                                                                             |
| `Super Return`                               | Zoom in (bump the focused view to the top of the layout stack).                                                                                                      |
| `Super H`                                    | Decrease the main ratio in **rivertile** layout by `0.05`.                                                                                                           |
| `Super L`                                    | Increase the main ratio in **rivertile** layout by `0.05`.                                                                                                           |
| `Super+Shift H`                              | Decrease the main count in **rivertile** layout by `1`.                                                                                                              |
| `Super+Shift L`                              | Increase the main count in **rivertile** layout by `1`.                                                                                                              |
| `Super+Alt H`                                 | Move the focused view left by `100`.                                                                                                                                  |
| `Super+Alt J`                                 | Move the focused view down by `100`.                                                                                                                                  |
| `Super+Alt K`                                 | Move the focused view up by `100`.                                                                                                                                   |
| `Super+Alt L`                                 | Move the focused view right by `100`.                                                                                                                                |
| `Super+Alt+Control H`                        | Snap the focused view to the left edge of the screen.                                                                                                               |
| `Super+Alt+Control J`                        | Snap the focused view to the bottom edge of the screen.                                                                                                             |
| `Super+Alt+Control K`                        | Snap the focused view to the top edge of the screen.                                                                                                                |
| `Super+Alt+Control L`                        | Snap the focused view to the right edge of the screen.                                                                                                              |
| `Super+Alt+Shift H`                          | Resize the focused view horizontally by `-100` pixels.                                                                                                               |
| `Super+Alt+Shift J`                          | Resize the focused view vertically by `100` pixels.                                                                                                                 |
| `Super+Alt+Shift K`                          | Resize the focused view vertically by `-100` pixels.                                                                                                                |
| `Super+Alt+Shift L`                          | Resize the focused view horizontally by `100` pixels.                                                                                                               |
| `Super Space`                                | Toggle floating for the focused view.                                                                                                                                 |
|
